How Governor Works

A single permission check between intent and action.

Step 1

Agent Proposes

Any agent can request an escalation at any time. Sales wants a popup. Marketing wants a notification.

Agent request
escalate(userId, "popup")
Step 2

Governor Checks

One question: "Is escalation allowed for this user right now?" No reasoning. No planning. Just enforcement.

Governor response
{ 
  allowed: true | false, 
  reason: "..." 
}
Step 3

Execute or Block

Allowed actions execute. Blocked actions wait or downgrade. The user is protected.

Allowed
Blocked

Pressure Limits

Per-user pressure cannot exceed threshold. Agents must wait.

Cooldown Periods

Same escalation type has minimum interval. No rapid fire.

Mutual Exclusion

Only one popup at a time. Only one banner at a time. Coordinated.
