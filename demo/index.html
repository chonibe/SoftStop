How Governor Works

Step 1

Agents Propose Actions

Every AI agent can request escalations at any time. Sales wants a popup. Marketing wants a banner. Retention wants a discount modal.

Step 2

Governor Checks Permission

Before any action executes, Governor asks: "Is this user already under too much pressure?" One API call. Instant decision.

Step 3

Execute or Block

Allowed actions proceed. Blocked actions are logged and must wait. The user is protected from pressure stacking.
