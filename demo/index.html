SoftStop

Doesn't make software smarter.
Makes it stop when it should.

The shared authorize-only permit before any system raises pressure on a user. One check before urgency, discount, interruption, or reminder — then record.

Quick start

Run it in under five minutes

Full README →
Self-host 
pnpm install
pnpm dev
pnpm softstop verify
check before escalate 
curl -X POST http://localhost:3000/v1/check \
  -H 'content-type: application/json' \
  -d '{"userId":"user_123","actionType":"urgency","surface":"email"}'

SoftStop does not send email or write copy. Your systems still decide what to say — SoftStop decides whether they’re allowed to push. Docker: docker compose up --build

Contract

Authorize only

Ask SoftStop before raising pressure. Get allow or block. Record the outcome. Same gate for marketing, product UI, and agents.

SoftStop does

  • check → allow or block
  • record the outcome
  • Enforce cooldowns & caps across systems

SoftStop does not

  • Send messages
  • Personalize content
  • Optimize conversion
