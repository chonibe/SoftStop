How Governor Works

A single permission check between intent and action.

Step 1

Agent Proposes

Any agent can request an escalation at any time. Sales wants a popup. Marketing wants a notification.

Agent request
escalate(userId, "popup")
Step 2

Governor Checks

One question: "Is escalation allowed for this user right now?" No reasoning. No planning. Just enforcement.

Governor response
{ 
  allowed: true | false, 
  reason: "..." 
}
Step 3

Execute or Block

Allowed actions execute. Blocked actions wait or downgrade. The user is protected.

Allowed
Blocked

Pressure Limits

Cooldown Periods

Mutual Exclusion

Only one popup at a time. Only one banner at a time. Coordinated.

Governor integrates in minutes. Every agent asks permission. Every escalation is tracked.

// Before any escalation
const decision = await governor.check({
  userId: "user_123",
  agentId: "sales-agent",
  escalationType: "popup",
  pressure: 25
});

if (decision.allowed) {
  showPopup(user);
} else {
  // Agent must wait or downgrade
  console.log(decision.reason);
  // "Cooldown active for popup"
  // "Would exceed pressure limit"
}
