# SoftStop Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) Code of Conduct (v2.1).

## Our Pledge

We as members, contributors, and leaders pledge to make participation in our community a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

## Enforcement

Report unacceptable behavior to the maintainers via [GitHub private vulnerability reporting](https://github.com/chonibe/SoftStop/security/advisories/new) for security-sensitive cases, or open a confidential maintainer contact through GitHub Issues marked `conduct` for community issues.

For the full text, see: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
