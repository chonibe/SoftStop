# SoftStop: Single Killer Slide

## Slide Content (single slide)

**Title:** SoftStop  
**Subtitle:** A control layer that stops automated systems from over-pushing users

**Core line:**  
SoftStop doesn’t make software smarter. It makes it stop when it should.

**Visual (one line):**  
Escalation Systems -> SoftStop Gate -> User

**Problem (one line):**  
Multiple automations stack pressure; no one asks "has this user already been pushed enough?"

**Why platforms (one line):**  
Multi-agent platforms: pressure stacking becomes a platform-level risk.

**Outcome (one line):**  
SoftStop blocks excessive escalation while preserving user choice.
