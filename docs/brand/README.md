# SoftStop brand

## Mark

Soft halt bar through a geometric **S** — permit/block without looking like a hard stop light or security shield. Background is always transparent.

- Ink: `#0B0B0F`
- Paper: `#F7F5F0`
- Stop amber: `#E8A317`

## Do

- Flat, one accent color
- SoftStop as one word
- Transparent mark backgrounds (no filled tile)
- Pressure permit / stop-when-it-should framing

## Don't

- Purple AI gradients, glow orbs, baby soft-spot literalism
- Shield/lock IAM vibes
- Opaque white or black square behind the mark
- MCP / agent-firewall framing on the mark
