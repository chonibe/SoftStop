# SoftStop brand

## Mark

**Locked mascot:** fluffy beaver peeping over a log (`masters/beaver-canonical-locked.png`). All pose variants must match this face — do not redesign.

Beaver on a log — SoftStop’s soft halt as a dam on pressure. Default app icon is the beaver tile; geometric **S** marks remain for wordmark companions.

- Ink: `#0B0B0F`
- Paper: `#F7F5F0`
- Stop amber: `#E8A317`

## Do

- Flat, one accent color
- SoftStop as one word
- Default surfaces use the rounded icon tile or logo-only cover
- Transparent marks when compositing on existing UI chrome
- Pressure permit / stop-when-it-should framing

## Don't

- Purple AI gradients, glow orbs, baby soft-spot literalism
- Shield/lock IAM vibes
- MCP / agent-firewall framing on the mark
- Crowding the social cover with taglines — keep it logo-only
