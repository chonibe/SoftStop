# MCP Integration (experimental)

> **SoftStop v0.1:** The public product is the **pressure permit** (`check` / `record` on user escalations). Full MCP tool-call gateway material is archived at [archive/mcp-gateway](../archive/mcp-gateway). Prefer [examples/agent-touchpoint](../examples/agent-touchpoint) when an agent escalates a human.

SoftStop belongs at the boundary where an AI system is about to **raise pressure on a user** (email, SMS, modal, discount). Call SoftStop `check` before that escalation and `record` after.

For experimental tool-call authorization sketches, see `packages/` and [archive/mcp-gateway](../archive/mcp-gateway).
